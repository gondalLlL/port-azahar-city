**Port Azahar** — an original top-down open-world crime game that runs in the browser from static files. Play Dario Venn, a driver in a coastal city of five named districts, running a five-mission story for fixer Marisol Kane: a timed package run, a stolen sports car, a three-star escape to a safehouse, three cash drops under rising police pressure, and a final dash to the marina. Explore on foot or steal any car; traffic follows lanes, pedestrians wander and flee, crimes raise a five-star wanted level with police pursuit and a busted meter, and fists and a pistol settle arguments. HUD with health, armor, cash, wanted stars, mission tracker and a live minimap; title, pause, busted and wasted screens; progress saves to localStorage; synthesized WebAudio engine, sirens and radio — no assets, no network.

## Run it

```sh
node serve.ts        # then open http://localhost:8080
```
